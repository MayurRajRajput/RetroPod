RETROPOD 2.8.0 PROJECT CONTENTS

app/src/main/java/com/retropod/player:
- MainActivity.kt      Activity, app root, tabs, bottom nav, overlay host, dialogs
- AppState.kt          Library, playback mirror, settings, playlists, backup, delete
- PlaybackService.kt   Media3 service: notification tap, equalizer, visualizer, sleep timer
- Components.kt        Artwork cache, chips, rows, mini player, wave seek bar, sliders, dial
- ScreenHome.kt        Splash + Home
- ScreenLibrary.kt     Songs, Search, Cover Flow/Albums, Playlists, context menu
- ScreenPlayer.kt      Now Playing, Lyrics, Queue
- ScreenAudio.kt       Visualizer, Equalizer, Sleep Timer
- ScreenSettings.kt    Settings pages
- Library.kt           MediaStore scan, lyrics parser, helpers
- LockScreenActivity.kt  Album-art player shown over the lock screen (Settings > Lock Screen)
- ClickSound.kt       SoundPool click used by the Cover Flow wheel and controls (res/raw/wheel_click.wav)
- Theme.kt, Song.kt, RetroPodApplication.kt

Build: GitHub Actions (.github/workflows/build-apk.yml) or Android Studio. Not compiled in the authoring environment.
