# RetroPod staged roadmap

Each stage ZIP is cumulative and retains all previous stage changes.

1. **Foundation and app structure** — project baseline, AMOLED monochrome system theme, navigation/component foundation. (This archive.)
2. **Home screen and Cover Flow** — finished 3D album carousel, reflections, artwork treatment, home sections and motion.
3. **Music player** — Now Playing redesign, playback controls, waveform/progress seek, shuffle/repeat and in-app volume.
4. **Music library** — Songs/Albums/Playlists polish, search, A–Z fast-scroll, contextual actions, details and sharing.
5. **Playlist and queue management** — create/rename/delete/reorder playlists, song membership editing, queue reorder/remove.
6. **Audio features** — Android AudioEffect equalizer, sleep timer, embedded/local lyrics and playback preferences.
7. **Background playback** — notification/lock-screen behavior, background service lifecycle and saved paused playback restoration.
8. **Settings and personalization** — complete settings, haptics/click sounds, animation preferences, library management and backup/restore.

## Quality gate
Keep previous changes; inspect source/resource references; run available static checks and ZIP integrity checks; run Gradle builds and device/emulator tests when an Android build environment is available; disclose anything not tested.
